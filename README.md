# Μπάρα Καπυμπάρα

Πρωτότυπο σελίδας καμπάνιας: «Μπάρα για να τρώνε μεγάλα καπυμπάρα».

- **Επιλογή 1:** φωτογραφία της συμπληρωμένης συλλογής αυτοκόλλητων (το κουτί-άλμπουμ) για συμμετοχή στην κλήρωση.
- **Επιλογή 2:** παιχνίδι όπου ντύνεις ένα καπυμπάρα.

Όλη η σελίδα είναι το `index.html`, χωρίς βήμα build.

## Τι λείπει για πραγματική χρήση

- Η υποβολή είναι δοκιμαστική: τίποτα δεν αποστέλλεται. Η συνάρτηση `submitEntry` στο `index.html` είναι το σημείο όπου συνδέεται ο server.
- Όροι κλήρωσης, ημερομηνία, όνομα μάρκας και αριθμός αυτοκόλλητων (βλ. `CONFIG`).
- Συγκατάθεση γονέα/κηδεμόνα για ανήλικους.
